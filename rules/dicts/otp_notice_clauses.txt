# 通知式验证码投递的判定要素（"告知"侧，非"索取"）
#
# 用途：otp_notice 特征 = 给出码值 + 附带下列任一"有效期/防泄露/忽略"条款。
# 真实验证码投递必然带码值并说明有效期或"请勿泄露"，而钓鱼的"验证码话术"是
# 用码诱导点击/回填，通常没有这些条款。判定要求**码值 + 条款同时出现**（且都在
# 验证码关键词附近），避免把"验证码"三个字当成豁免依据。
#
# 来源：QQ 邮箱真实通知邮件实证（哔哩哔哩/百度/vivo/量子ACG 等），不做推测性扩充。
# 2026-09 规则语义审查补入"小时内/失效/与任何人分享/hour/min/invalid"等：原词表与
# 真实通知的实写措辞不匹配，导致百度（"请在1小时内完成验证"）、Apple（"三小时失效"）、
# Steam（"切勿与任何人分享此代码"）等**合法通知**不被认定，白扣 body_otp(5)+
# body_credentials(7)。补齐后邮箱侧 13 封转为豁免、判定净收益 1 封（SUSPICIOUS→BENIGN），
# pot/datacon 召回 0 损失（5 封钓鱼获得豁免但判定不变）。
