# 易滥用平台（abuse-prone）：**流量很高、但不能当"可信"**的域，两处用途：
#
# 1. 生成可信域清单时**排除**（`scripts/update_trusted_domains.py`）：这些域在 Tranco /
#    Cisco / Cloudflare / Majestic 的 top 榜上，但钓鱼、诈骗页面常年寄居其上（免费建站、
#    网盘、粘贴板、短链、用户内容 CDN、在线表单）。若因为"知名"就跳过情报查询，等于对
#    `xxx.pages.dev` / `xxx.github.io` / `drive.google.com/...` 这类链接永久失明。
#    实测：四份榜单合并后，"易滥用平台"里有 36 个在榜（见 README_dev 记录）。
# 2. 将来做「链接托管在易滥用平台」的弱信号时直接复用（列表本身与方向无关）。
#
# 判定口径：**可注册域**（与项目其它域判定一致）。`drive.google.com`/`docs.google.com`
# 这类"大厂域名下的用户内容子域"在本口径下**无法单独列出**（它们收敛到 google.com）——
# 这是已知缺口，写在 README_dev 里；真要精确覆盖得改成主机级匹配，等有实测需求再做。
#
